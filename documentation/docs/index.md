## Editions

Report Server is published as **Open Source** and **Professional** packages. Datasource engines in the admin UI are on both. The Open Source package does not compile Professional modules. A Professional package without a license includes Data Explorer and embedded QGIS; Map Reports and the other license-gated modules stay off until a license is valid. `ACUGIS_EDITION` does not grant features. See the [compatibility matrix](reference/compatibility-matrix.md).

## Client environment

Use these environment variables with the CLI and SDKs. A packaged server uses base path `/`.

```bash
export ACUGIS_REPORT_URL=https://reports.example.com
export ACUGIS_REPORT_TOKEN=jrs_xxxxxxxxx
```

A local package is reached at `http://127.0.0.1:9088`. If `JRS_BASE_PATH` is set, include that prefix in `ACUGIS_REPORT_URL`.

## Live API on your server

When Report Server is running, the OpenAPI contract and Swagger UI are served relative to the server base path:

| Path | Purpose |
|------|---------|
| `/swagger` | Swagger UI |
| `/api/openapi.yaml` | OpenAPI 3.0 YAML |
| `/api/openapi.json` | OpenAPI 3.0 JSON |

If `JRS_BASE_PATH=/go`, use `/go/swagger` and `/go/api/openapi.yaml`.
