# OpenAPI (reference)

Authoritative contract locations:

| Source | Location |
|--------|----------|
| Live YAML | `/api/openapi.yaml` |
| Live JSON | `/api/openapi.json` |
| Swagger UI | `/swagger` |
| Repo bundle | `sdk/openapi.bundle.yaml` |
| Modular sources | `go-report-server/openapi/` |

With `JRS_BASE_PATH=/go`, prefix paths accordingly.

For generation, Postman, and `operationId` rules see [Developer Guide — OpenAPI](../developer/openapi.md).
