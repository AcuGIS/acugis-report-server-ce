# User Guide

This guide explains AcuGIS Report Server from the perspective of people who author, organize, run, and explore reports in the product UI.

Use this section when you want to understand **what Report Server does** — reports, folders, parameters, maps, and permissions — without starting from REST endpoints or SDK samples.

## Who this is for

- Report authors and publishers
- Users who run reports and manage catalog content
- Anyone learning the product before integrating APIs
