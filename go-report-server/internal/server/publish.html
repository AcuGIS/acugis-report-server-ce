Thumbnail

CQL is taken automatically from the uploaded JRXML (Report Designer). Select a Server Cassandra/Astra datasource for connection credentials only — do not re-enter the query.

GoogleSQL is taken automatically from the uploaded JRXML (Report Designer collection query). Select a Server Google BigQuery datasource for Project ID and Service Account credentials only — do not embed Designer JSON paths or keys.

ArcGIS attributes are read from the JRXML (acugis.datasource.connection). Select the ArcGIS Feature Server datasource with that exact name. Report Server keeps its own credentials and does not copy them from Designer.

DuckDB SQL is taken automatically from the uploaded JRXML (language=SQL; legacy language=duckdb still works). Map to a Server DuckDB Datasource. Reports fill via DuckDB JDBC REPORT_CONNECTION (not collection data). Local Designer .duckdb paths are not portable — use a Server filesystem path for Database mode. Remote Data Files authentication is resolved from the Server Datasource (never from JRXML).
