AcuGIS Report Server — bundled fonts

This directory is a JasperReports font extension packaged inside the WAR
(WEB-INF/classes/fonts/). Fonts are freely redistributable open-source faces.

Registration
------------
jasperreports_extension.properties registers SimpleFontExtensionsRegistryFactory
with fonts/fonts.xml. Alias families (visible=false) cover common Windows names
so existing JRXML continues to work without host OS fonts.
